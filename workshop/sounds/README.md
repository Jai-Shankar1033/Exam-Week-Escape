# 🎵 Sound Effects Folder

Put your custom sound effects here!

## Supported Formats
- WAV (.wav) - High quality (the included sounds)
- MP3 (.mp3) - Most common
- OGG (.ogg) - Good compression (not supported by every browser)

## Sound Files The Game Uses
The names are set in `lib/workshop/game_settings.dart`
(`jumpSound`, `scoreSound`, `hitSound`, `swooshSound`).
Replace a file with your own, or change the name in that file.

| File | Plays when | Tip |
| --- | --- | --- |
| **jump.wav** | the bird flaps | very short (0.1 - 0.5 s) |
| **score.wav** | you pass a pipe | short (0.2 - 0.8 s) |
| **hit.wav** | you crash | can be longer (0.3 - 2 s) |
| **swoosh.wav** | the game starts / restarts | short |

The included effects (and the music) were generated by `tools/generate_audio.py`,
so they are original and free to use.

> 🎵 **Background music** is not in this folder. It lives in
> `assets/audio/music/` (`menu.wav` and `game.wav`) and is set in the
> "BACKGROUND MUSIC" part of `lib/workshop/game_settings.dart`.

## 💡 Tips
- Short sounds work best for games
- Not too loud!
- You can record your own voice!
- Test in the game and adjust

## 🎨 Where to Get Sounds?
- Record your own voice/sounds!
- Search "free game sound effects" online
- Use sites like: Freesound.org, Zapsplat.com
- Make sounds with household objects
- Use your phone's voice recorder

## 🎤 Recording Your Own Sounds (Kids Love This!)
1. Use your phone or computer microphone
2. Make cool sound effects with your mouth
3. Record it
4. Save as MP3
5. Add to this folder!

**Ideas:**
- "Boing!" for jump
- "Ding!" for score
- "Wah wah wahhh" for game over
- Animal sounds
- Silly voices
