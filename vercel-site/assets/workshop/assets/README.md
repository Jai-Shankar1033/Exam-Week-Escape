# 🖼️ Custom Images Folder

Put your custom images here!

## Supported Formats
- PNG (.png) - Best for sprites
- SVG (.svg) - Good for simple shapes
- JPG (.jpg) - Works but use PNG instead

## Image Files You Can Add

### 1. **bird.png** or **bird.svg**
Your custom bird character!
- Recommended size: 40x40 to 80x80 pixels
- Can be anything: a plane, rocket, character, emoji, etc.

### 2. **pipe.png** or **pipe.svg**
Your custom obstacles!
- Recommended width: 60-100 pixels
- Can be: buildings, trees, lasers, anything tall!

### 3. **background.png** or **background.svg**
Your custom background!
- Should match your game screen size
- Can be: space, underwater, city, forest, etc.

## 💡 Tips
- Keep images small (under 500KB)
- Use transparent backgrounds (PNG)
- Simple designs work best for games

## 🎨 Where to Get Images?
- Draw your own!
- Use free emoji
- Search "free game sprites" online
- Use tools like: GIMP, Paint, Photoshop, or online editors
